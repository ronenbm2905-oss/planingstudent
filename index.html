      Google Calendar

      מבחנים, הגשות ושיעורים מ-Moodle, אוטומטית
      לא מחובר
      בודק אם אפשר להתחבר ל-Google Calendar…
      איך מחברים?
      1. ב-Moodle: לוח שנה ← ייצוא לוח שנה ← קבלת כתובת URL ללוח השנה, ומעתיקים.
      2. ב-Google Calendar במחשב: יומנים אחרים ← + ← מכתובת URL ← מדביקים ← הוספת יומן.
      3. ב-claude.ai מחברים את Google Calendar: הגדרות ← Connectors.
      4. לוחצים על הכפתור ובוחרים את יומן ה-Moodle. הבדיקה חוזרת כל 30 דקות כשהדף פתוח.

      קובץ מ-Moodle

      ייבוא ידני, בלי התחברות
      לא יובא
      איך מורידים את הקובץ?
      1. נכנסים ל-Moodle של המכללה ופותחים את לוח השנה.
      2. ייבוא או ייצוא לוחות שנה ← ייצוא לוח שנה.
      3. בוחרים כל האירועים ואת התקופה הארוכה ביותר ← ייצוא.
      4. גוררים לכאן את הקובץ שירד. כדי לקבל עדכונים, חוזרים על זה מדי פעם.

      מדיניות פרטיות: שעת דין

      שעת דין הוא מתכנן לימודים שרץ כולו בדפדפן שלך. אין לו שרת, ואין בו הרשמה.

      איזה מידע נשמר

      מבחנים, אילוצים, משימות, ציונים ומיילים שהוספת נשמרים רק בדפדפן שלך (localStorage). הם לא נשלחים אלינו ולא לאף צד שלישי. מחיקה של נתוני האתר בדפדפן, או הכפתור "התחלה מאפס", מוחקת אותם.

      התחברות עם Google

      אם בחרת להתחבר עם Google, האפליקציה מבקשת הרשאת קריאה בלבד ליומן Google (calendar.readonly), כדי לייבא מבחנים והגשות מיומן ה-Moodle שלך. היא לא יוצרת, לא משנה ולא מוחקת אירועים. אם הופעלה גם קריאת מיילים, ההרשאה היא קריאה בלבד (gmail.readonly), ונקראים רק מיילים שנשלחו מכתובת המכללה שהוגדרה.

      אסימון ההתחברות נשמר רק בזיכרון הדף, לשעה לכל היותר, ונמחק כשסוגרים את הדף. המידע שנקרא מ-Google מוצג ונשמר רק בדפדפן שלך.

      השימוש של האפליקציה במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

      ביטול גישה

      אפשר לבטל את הגישה בכל רגע בדף הרשאות של חשבון Google.
